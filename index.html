Projects

Alcedo Studio

A free and open-source photo editor and library for Windows (CUDA / OpenCL) and Apple Silicon Macs (Metal), written in C++20 with Qt/QML.
[ Source on GitHub ] [ Project Website ]

  • RAW support — decodes RAW files from Canon, Nikon, Sony, Fujifilm, Panasonic, OM System, Leica, Hasselblad, Phase One, Pentax and Sigma, as well as DNGs from phones and drones. Implemented a LibRaw fork that adds support for Nikon HE/HE* NEFs and speeds up lossless JPEG decoding.
  • Scene-referred color pipeline — 32-bit floating-point scene-linear processing with ACES 2.0 and OpenDRT output transforms, node-based color grading with masks, film LUTs and custom 3D LUTs.
  • DAG-based GPU pipeline — edits evaluated as a cached directed acyclic graph on CUDA, OpenCL and Metal; only downstream nodes recompute, and zoomed views render just the visible region.
  • Local asset management — an embedded DuckDB catalog for fast filtering, plus on-device multilingual CLIP tagging for natural-language search without the cloud.
  • Branching version history — a Git-like version tree for every photo: branch from any step and copy looks across images.
  • CLI & agent collaboration — every UI action maps to alcedo-cli; with alcedo-skills, agents like Claude Code or Codex can batch-process photos or work in the live window.
